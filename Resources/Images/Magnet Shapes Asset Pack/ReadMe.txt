Hi! Thanks for downloading my art asset pack!

This pack includes a collection of magnet-themed geometric shapes: squares, triangles, rectangles, and circles. They come in either three or four variations, depending on the shape. These are: positive, negative, neutral, and split (both positive and negative). 

The pack is organized into three folders. The PNGs folder contains individual PNG-formatted images. The XCFs folder has editable GIMP source files for customization. Finally, the Spritesheets folder provides two compiled PNG spritesheets (a "square" and a "line" shaped) and a JSON file for easy integration with game engines like Unity or Godot.
